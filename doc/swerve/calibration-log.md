# Swerve calibration log

Record every change to a module offset or the wheel radius here, in the same
PR that changes the robot config. If one module's offset keeps changing, look
for a loose CANcoder magnet or a slipping module before recalibrating again.
See the [tuning and calibration guide](tuning-and-calibration.md) for the
procedure.
